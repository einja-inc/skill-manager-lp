# Skill Manager LP — ver1

LPの共有確認用スナップショットです。正本のローカル実装から派生した静的プレビューです。

公開URL: https://einja-inc.github.io/skill-manager-lp/

- `docs/` のみGitHub Pagesへ公開します。
- フォームは確認専用。個人情報を入力・送信・保存できません。
- API、秘密情報、Webhook、受付データは含みません。
- 開発中の製品説明と元資料の画像を使用しています。Higgsfieldでの追加制作と本番受付連携は未完了です。
- `ver1`タグでこの版を保存します。

## 明るい別案 — Bright edition

比較用URL: https://einja-inc.github.io/skill-manager-lp/bright.html

白・淡い紫・温かいベージュを基調に、個人の工夫を組織で共有するストーリーを構成。元のver1はそのまま残しています。営業提案の架空例、製品画面切り替え、実行トレース、導入ステップを掲載しています。CTAは共通の確認専用フォームへ移動します。

検証: 320/390/768/1440pxの横はみ出し、タブのクリック・矢印キー操作、画面拡大の開閉、画像読み込みをブラウザで確認。マーケティング・実装・ユーザー目線のレビュー指摘を修正済み。メインビジュアルには、指定参照画像をElementsに登録しNano Banana Proで生成した画像を使用しています。生成画像は加工せず全体を掲載しています。
